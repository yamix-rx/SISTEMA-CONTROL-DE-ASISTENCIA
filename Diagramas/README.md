# Diagramas

- `DiagramaBD.mmd`: esquema entidad-relación actual, generado desde `backend/base-actualizada.sql`, con las 18 tablas y sus claves foráneas. Puede visualizarse con un visor Mermaid compatible.
- Regeneración: `npm run diagrama` desde `backend`.
- `Diagrama1.PlantUML` y `Diagrama2.PlantUML`: casos de uso. Las solicitudes de permisos desde el perfil pertenecen a una etapa futura.

El antiguo archivo `diagrama-base.mwb` estaba incompleto (39 bytes); no se utiliza como modelo de la base actual.
